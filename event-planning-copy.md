# Event Planning – Feature Gaps

## Starter — Free | 1–2 events/year

| Feature | Gap |
|--------|-----|
| **Customizable tasklist** | No tasklist/checklist UI or templates in app; only in pricing copy. Need event-level task templates and editable tasklists. |
| **Sending RFPs** | No RFP send flow. We have explore vendors, messaging, and contracts, but not "send RFP" or automated RFP/negotiation. |
| **AI proposal negotiation** | Only mentioned in copy (e.g. VendorDetail "Waddi agents can negotiate"). No AI negotiation tool in app. |
| **AI itinerary build** | AI only pre-fills event form. Itinerary builder is manual; no "AI builds the itinerary" flow. |
| **Guest website** | Need a real guest-website page (and/or public RSVP page) so "create in one click" is functional. |
| **RSVPs** | GuestsTab shows list and "RSVP Website"; no actual RSVP form or "remembers preferences" logic. |

## Pro — NGN 150,000/month (annual) | 3+ events/year

| Feature | Gap |
|--------|-----|
| **Company policies** | No UI for per-person budget, guest policy, location requirements, etc. |
| **Approval flows** | No preferred vendors list or approval workflow in app. |
| **Custom insights** | No dashboard or report for events, guests, budget, venues, RFPs, users. |
| **Content templates** | No templates for icebreakers, meetings, workshops, games. |

## Enterprise — Custom | Compliance & integrations

| Feature | Gap |
|--------|-----|
| **Custom Contract Workflows** | No configurable approval workflows for contracts. |
| **SSO Integration** | Auth is Firebase (e.g. Google); no SSO. |
| **Custom Integrations** | No integrations framework or UI. |
| **Multi-Entry Billing** | No billing or multi-source billing in app. |

---

**Summary:** Core marketplace and event management exist. Missing: tasklist, RFP flows, AI negotiation/itinerary, functional guest website/RSVP, all Pro features (policies, approvals, insights, templates), and all Enterprise features (SSO, integrations, billing, workflow config).
